# School Bus Safety Tracker

A Flask-based web application prototype for managing student
transport records and boarding status.

## Current Features
- View student transport records
- Search by student name, bus, or class
- Update student boarding status

## Technology Stack
- Python
- Flask
- HTML
- Jinja2

## Run Locally
1. Install Python 3.
2. Install dependencies:
   pip install -r requirements.txt
3. Start the application:
   python app.py
4. Open http://127.0.0.1:5000 in your browser.

Note: This is an academic prototype. Live GPS tracking,
database persistence, and automated notifications are
planned enhancements.
